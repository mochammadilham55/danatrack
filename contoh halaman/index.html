DanaTrack — Pilihan Arah Desain

Tiap kartu berisi mockup 9 halaman utama dalam satu file. Klik untuk buka, lalu pakai tombol navigasi di bagian atas file untuk pindah antar halaman.

Desain 1 — Minimalis Bersih

Navbar atas, kartu putih, aksen indigo, banyak whitespace. Evolusi halus dari tampilan yang sudah ada sekarang — rapi dan aman, risiko paling kecil.

Desain 2 — Vibrant Modern

Sidebar gelap, kartu statistik gradasi warna, tombol pil, tag kategori berwarna. Lebih hidup dan ramah untuk pengguna harian, kesan "aplikasi keuangan personal" modern.

Desain 3 — Korporat / Fintech Gelap

Dark mode penuh, sidebar gelap, tabel padat data, angka pakai font mono. Kesan dashboard profesional/fintech — cocok kalau mau dipakai lama di depan layar.
